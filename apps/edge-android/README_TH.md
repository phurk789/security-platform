# คู่มือแอป 13STORE Edge บนรีโมต SIYI UniRC 7 Pro

แอปนี้ทำหน้าที่เดียวกับชุด Termux เดิม (`deploy/remote/`) คือรัน Gateway บนรีโมต
ให้รถส่งข้อมูลและวิดีโอขึ้นแพลตฟอร์ม แต่ **ไม่ต้องพิมพ์คำสั่งและไม่ต้องพิมพ์คีย์**
มีแค่ปุ่ม "จับคู่" กับปุ่มใหญ่ปุ่มเดียว "▶ เริ่ม / ■ หยุด"

- จับคู่ครั้งเดียวด้วยรหัส 6 หลักจากหน้าเว็บ แอปจะได้คีย์ Gateway เองโดยไม่มีใครเห็นคีย์
- ปิดจอได้ แอปยังทำงานต่อ และมีแจ้งเตือนค้างไว้ให้รู้ว่ากำลังทำงาน
- หน้าจอแอป (ตั้งแต่ 0.3.0 เป็นธีมมืด 2 คอลัมน์เมื่อถือรีโมตแนวนอน):
  - **ซ้าย**: สถานะ Gateway ตัวใหญ่ (ไฟเขียว = ทำงาน, เทา = หยุด, เหลือง = กำลังเริ่ม/หยุด), เวลาออนไลน์ และปุ่มใหญ่ เริ่ม/หยุด
  - **ขวา**: เชื่อมต่อเซิร์ฟเวอร์ได้ไหม, มีสัญญาณจากรถไหม, ส่งวิดีโออยู่ไหม และบันทึกล่าสุด
  - **⚙ มุมขวาบน**: เปิด/ปิดหน้าตั้งค่า

> **กฎสำคัญ:** ลิงก์ข้อมูลของรถใช้ได้ **ทีละโปรแกรม** ตั้งแต่เวอร์ชัน 0.3.0 แอปเป็นตัวกลางให้ UniGCS:
> ตั้ง UniGCS ให้ต่อ **ผ่านแอป** (UDPCL `127.0.0.1` พอร์ต `19857`) แล้วใช้ UniGCS กับแพลตฟอร์มพร้อมกันได้ (ข้อ 4.1)
> ถ้า UniGCS ยังต่อตรงเข้าลิงก์ข้อมูล (`192.168.144.20:19856`) ต้องปิด UniGCS ก่อนกด "เริ่ม"

## 2. ติดตั้งแอป (ครั้งแรก)

1. คัดลอกไฟล์ APK ลงรีโมต ใช้สาย USB, แฟลชไดรฟ์ หรือดาวน์โหลดผ่านเบราว์เซอร์บนรีโมตก็ได้
2. บนรีโมตเปิดแอป **Files** (ตัวจัดการไฟล์) แล้วแตะไฟล์ `13store-edge-....apk`
3. ถ้าขึ้นว่า "ไม่อนุญาตให้ติดตั้งแอปจากแหล่งนี้" ให้กด **การตั้งค่า** แล้วเปิด **อนุญาตจากแหล่งนี้**
   จากนั้นกดย้อนกลับ
4. กด **ติดตั้ง** แล้วรอจนเสร็จ จากนั้นกด **เปิด**
5. แอปชื่อ **13STORE Edge** (ไอคอนเสาอากาศสีขาวบนพื้นน้ำเงินเข้ม)

> ถ้า Play Protect เตือนว่า "แอปไม่รู้จัก" ให้กด "ติดตั้งต่อ" เพราะแอปนี้ไม่ได้มาจาก Play Store

## 3. จับคู่รีโมตกับแพลตฟอร์ม (ครั้งเดียว)

### 3.1 ผู้ดูแล ทำบนหน้าเว็บ

1. เปิดหน้าเว็บด้วยที่อยู่ในเครือข่าย **http://192.168.20.13:8090** แล้วเข้าสู่ระบบเป็นผู้ดูแล
   (ห้ามใช้ `localhost` เพราะ QR จะพาไปที่อยู่ที่รีโมตเข้าไม่ถึง หน้าเว็บจะเตือนถ้าเปิดแบบนั้น)
2. ไปที่ **ผู้ดูแล**
3. ถ้ายังไม่เคยลงทะเบียนรถ: ในการ์ด **Edge Gateway และอุปกรณ์** พิมพ์ `UGV-01` เลือก `UGV` แล้วกด **ลงทะเบียน**
4. ในการ์ด **จับคู่รีโมต (Edge)** ค่าที่ตั้งไว้ให้ใช้ได้เลย:
   - ชื่อ: `SIYI UniRC 7 Pro`
   - รหัส Gateway: `edge-unirc-01`
   - รหัสรถ: `UGV-01`
   - ที่อยู่กล้อง RTSP: `rtsp://192.168.144.25:8554/main.264` (ถ้าไม่ต้องการวิดีโอให้เว้นว่าง)
   - การขับรถจากหน้าเว็บเปิดไว้ให้แล้ว (`teleop`) แต่จะขับได้จริงก็ต่อเมื่อหัวหน้างานเลื่อนรถเป็น LIVE_MANUAL
     และผู้ควบคุมกดเริ่มขับ (ดู `deploy/remote/README_TH.md` §8.1) ถ้าไม่ต้องการให้ขับจากเว็บ ให้ติ๊ก
     "แก้รายการอุปกรณ์เอง (JSON)" แล้วลบบรรทัด `"teleop": true`
5. กด **สร้างรหัสจับคู่** จะได้ตัวเลข 6 หลักกับ QR **ใช้ได้ 10 นาที และใช้ได้ครั้งเดียว**
6. บอกตัวเลข 6 หลักกับคนที่ถือรีโมต (บอกทางโทรศัพท์หรือวิทยุก็ได้) ไม่ต้องส่งคีย์ใดๆ

### 3.2 คนถือรีโมต ทำในแอป

1. เปิดแอป **13STORE Edge** จะเห็นหัวข้อ **จับคู่กับแพลตฟอร์ม**
2. ช่องที่อยู่เซิร์ฟเวอร์มี `http://192.168.20.13:8090` ใส่ไว้ให้แล้ว (แก้ได้ถ้าเซิร์ฟเวอร์ย้าย)
3. พิมพ์ตัวเลข 6 หลัก แล้วกด **จับคู่**
   (ถ้ารีโมตมีกล้อง จะมีปุ่ม **สแกน QR** ให้กดแทนการพิมพ์ก็ได้)
4. ถ้าสำเร็จ หัวหน้าจอจะเปลี่ยนเป็น `edge-unirc-01 · พื้นที่ ... · http://192.168.20.13:8090`
   และในหน้าเว็บรหัสนั้นจะขึ้นป้าย **จับคู่แล้ว** พร้อมชื่อรุ่นรีโมต

ถ้าจับคู่ `edge-unirc-01` ซ้ำ (เช่น ลงแอปใหม่) คีย์ที่ได้จากการจับคู่ครั้งก่อนจะถูกยกเลิกให้เองโดยอัตโนมัติ
ส่วนคีย์ที่เคยสร้างเองสำหรับชุด Termux จะไม่ถูกยกเลิก ถ้าเลิกใช้ Termux แล้ว ผู้ดูแลกด **ยกเลิกคีย์** ของคีย์นั้นในการ์ด **API keys** ได้

## 4. ใช้งานประจำวัน

### เริ่มงาน

1. **UniGCS:** ถ้าตั้งให้ต่อผ่านแอปแล้ว (ข้อ 4.1) เปิดไว้ได้เลย ถ้ายังต่อตรงเข้าลิงก์ข้อมูล
   ให้ปิดก่อน: ตั้งค่า → แอป → UniGCS → **บังคับหยุด** (Force stop)
2. เปิดรถ และรอให้ลิงก์ของรีโมตต่อกับรถ
3. เปิดแอป **13STORE Edge** แล้วกดปุ่มใหญ่สีเขียว **▶ เริ่ม**
   - ครั้งแรกระบบจะถามเรื่องการแจ้งเตือน ให้กด **อนุญาต**
4. รอประมาณ 10 วินาที ดูสถานะ (จุดสีเขียว = ปกติ):

| หัวข้อ | ปกติจะขึ้นว่า |
|---|---|
| เซิร์ฟเวอร์ | ● เชื่อมต่อ ws://192.168.20.13:8090 แล้ว |
| รถ | ● UGV-01: สัญญาณจากรถปกติ (ข้อมูลล่าสุด 0.5 วินาทีที่แล้ว) |
| วิดีโอ | ● UGV-01: กำลังส่งวิดีโอ h264 ขึ้นแพลตฟอร์ม |

5. ในหน้าเว็บ รถ UGV-01 จะขึ้นเป็น **LIVE** และเห็นวิดีโอจากกล้อง
6. **ปิดจอรีโมตได้เลย** แอปยังทำงานต่อ บนแถบแจ้งเตือนจะมี "Gateway edge-unirc-01" ค้างไว้
   พร้อมสรุปสั้นๆ เช่น `เซิร์ฟเวอร์ ✓ · UGV-01 ✓ · วิดีโอ ✓`

### เลิกงาน

- กดปุ่มใหญ่ (ตอนทำงานจะเป็นสีแดง **■ หยุด**) ในแอป หรือกด **หยุด** จากแถบแจ้งเตือนก็ได้
- รอจนหัวข้อขึ้นว่า **Gateway หยุดอยู่**
- พอหยุด Gateway แล้ว UniGCS ที่ต่อผ่านแอปจะหลุดไปด้วย ถ้าจะใช้ UniGCS ต่อตอนไม่มี Gateway
  ให้ตั้ง UniGCS กลับเป็น UDPCL `192.168.144.20` พอร์ต `19856` ชั่วคราว

### 4.1 ใช้ UniGCS พร้อมกับแอป (ตั้งครั้งเดียว)

แอปต่อกับลิงก์ข้อมูลของรถอยู่โปรแกรมเดียว แล้วเปิดประตูในเครื่องที่ `127.0.0.1:19857` ให้ UniGCS
ข้อมูลรถไปถึงทั้ง UniGCS และหน้าเว็บพร้อมกัน และคำสั่งจาก UniGCS ไปถึงรถผ่านแอป

1. กด **▶ เริ่ม** ในแอปก่อน
2. เปิด UniGCS → การตั้งค่าการเชื่อมต่อ (ที่เคยตั้งเป็น UDPCL `192.168.144.20` พอร์ต `19856`)
   เปลี่ยนเป็น **UDPCL `127.0.0.1` พอร์ต `19857`** แล้วกดเชื่อมต่อ
3. ในแอป หัวข้อ **รถ** จะมีบรรทัด `● UniGCS: ต่อผ่านแอปนี้อยู่` และ UniGCS เห็นรถ โหลด parameter ได้ตามปกติ
   ถ้ายังขึ้น `UniGCS: ยังไม่ต่อ` ให้ตรวจที่อยู่และพอร์ตใน UniGCS อีกครั้ง

กติกาที่ต้องรู้:
- คำสั่งจาก UniGCS ไปถึงรถตรงๆ **ไม่ผ่านการอนุมัติของแพลตฟอร์ม** (เหมือนคันบังคับบนรีโมต)
  หน้าเว็บจะเห็นว่า UniGCS ต่ออยู่ และสั่งอะไรล่าสุด (เช่นเปลี่ยนโหมด, arm)
- ระหว่างที่หน้าเว็บกำลังขับรถ แอปจะ **ไม่ส่งคันบังคับเสมือนของ UniGCS** ต่อให้รถ เพื่อไม่ให้แย่งกันขับ
  แต่คำสั่งหยุดจาก UniGCS (เช่นเปลี่ยนเป็น HOLD หรือ disarm) ผ่านเสมอ
- สวิตช์ arm และสวิตช์โหมดบนตัวรีโมตใช้ได้เหมือนเดิมทุกกรณี

> รถจะอยู่ในโหมดดูอย่างเดียว (SHADOW) จนกว่าหัวหน้างานจะเลื่อนขั้นในหน้าเว็บหลังทดสอบความปลอดภัย
> แอปไม่ได้เปลี่ยนเรื่องนี้

## 5. ตั้งค่าในแอป (กด ⚙ มุมขวาบน)

ตั้งแต่ 0.3.0 หน้าตั้งค่าซ่อนไว้ กดปุ่ม **⚙** มุมขวาบนเพื่อเปิด กดอีกครั้งเพื่อปิด (เวอร์ชัน 0.2.0 อยู่ล่างสุดของหน้าจอ)

| ตั้งค่า | ควรตั้ง |
|---|---|
| **อนุญาตให้ทำงานตอนปิดจอ** | กดครั้งเดียวแล้วเลือก **อนุญาต** เพื่อไม่ให้ Android พัก Gateway ตอนปิดจอ |
| **เริ่ม Gateway เองเมื่อเปิดรีโมต** | **ปิดไว้** (ค่าเริ่มต้น) เปิดได้เมื่อ UniGCS บนรีโมตนี้ต่อผ่านแอปแล้ว (ข้อ 4.1) หรือไม่ได้ใช้ UniGCS ห้ามเปิดถ้า UniGCS ยังต่อตรงเข้าลิงก์ข้อมูล |
| **English / ภาษาไทย** | ปุ่มมุมขวาบน สลับภาษาหน้าจอ |
| **ยกเลิกการจับคู่ (ลบคีย์)** | ใช้เมื่อย้ายรีโมตไปใช้ที่อื่น ต้องหยุด Gateway ก่อน และต้องขอรหัสใหม่เพื่อจับคู่อีกครั้ง |
| **สัญญาอนุญาต** | ดูใบอนุญาตของ ffmpeg (LGPL), Node.js และส่วนอื่นที่อยู่ในแอป |

| ● UGV-01: รอสัญญาณแรกจากรถ / ไม่มีสัญญาณจากรถ | รถดับ, อยู่นอกระยะ, ลิงก์ยังไม่ต่อ, หรือ **UniGCS ต่อตรงเข้าลิงก์ข้อมูล** (`192.168.144.20:19856`) | ตั้ง UniGCS ให้ต่อผ่านแอป (ข้อ 4.1) หรือบังคับหยุด UniGCS, ตรวจไฟลิงก์บนรีโมตและรถ |

## 7. อัปเดตแอป (อัปเดตจากในแอปได้ ตั้งแต่เวอร์ชัน 0.2.0)

ตั้งแต่เวอร์ชัน **0.2.0** แอปอัปเดตตัวเองจากเซิร์ฟเวอร์ที่จับคู่ไว้ได้ ไม่ต้องเอาไฟล์ APK ไปลงที่รีโมตอีก
**ยกเว้นครั้งแรก:** ถ้ารีโมตยังเป็นเวอร์ชัน 0.1.0 (หรือยังใช้ชุด Termux) ต้องติดตั้งเวอร์ชันล่าสุดด้วยมือหนึ่งครั้ง
(ทำแบบข้อ 2 ติดตั้งทับได้ การจับคู่ยังอยู่) หลังจากนั้นอัปเดตจากในแอปได้ทุกครั้ง ดูเวอร์ชันที่ติดตั้งอยู่ได้ที่ล่างสุดของหน้าตั้งค่า
(⚙) เช่น `เวอร์ชัน 0.3.1 (6)`

| เวอร์ชัน | มีอะไรใหม่ |
|---|---|
| 0.3.1 (6) | Gateway รุ่นใหม่สำหรับเส้นทาง AUTO: อ่านเส้นทางกลับมาตรวจทุกจุดก่อนออกวิ่ง, นับว่า "เริ่ม" ก็ต่อเมื่อรถขยับจริง (ไม่ขยับใน 15 วินาที รถเข้า HOLD และแจ้งว่าไม่สำเร็จ), HOLD เมื่อถึงปลายเส้นทาง, แจ้งเมื่อเส้นทางถูกขัดจังหวะหรือวิ่งต่อ, ส่งความเร็วเส้นทาง (`WP_SPEED`) ให้หน้าเว็บ |
| 0.3.0 (5) | หน้าจอใหม่ธีมมืด 2 คอลัมน์, ปุ่มใหญ่ปุ่มเดียว เริ่ม/หยุด, เวลาออนไลน์, ตั้งค่าอยู่หลัง ⚙ · ใช้ UniGCS พร้อมกันผ่านแอป (ข้อ 4.1) · Gateway รุ่นใหม่: รั้วเสมือนตอนวิ่งภารกิจ (`missionFence`) |

| 0.1.0 (1) | รุ่นแรก จับคู่ด้วยรหัส 6 หลัก |

### 7.1 ผู้ดูแล เผยแพร่เวอร์ชันใหม่ (บนหน้าเว็บ)

1. ผู้พัฒนาส่งไฟล์มาให้ **2 ไฟล์คู่กัน** จากโฟลเดอร์ `apps/edge-android/dist/` เช่น
   `13store-edge-0.3.1.apk` กับ `13store-edge-0.3.1.json` (ไฟล์ .json บอกเวอร์ชันและค่าตรวจสอบของไฟล์ APK)
2. หน้าเว็บ → **ผู้ดูแล** → การ์ด **อัปเดตแอป Edge**
3. ช่อง **APK** เลือกไฟล์ `.apk` และช่อง **ไฟล์ .json** เลือกไฟล์ `.json` ของรุ่นเดียวกัน
4. กด **เผยแพร่ 0.3.1** (ระบบอาจถามรหัสผ่านอีกครั้ง) แล้วรอจนการ์ดขึ้นเวอร์ชันใหม่
   - เซิร์ฟเวอร์ตรวจว่าไฟล์ APK ตรงกับไฟล์ .json และเวอร์ชันใหม่กว่าที่เผยแพร่ไว้ ถ้าไม่ตรงจะไม่รับ
   - ไฟล์เก็บอยู่ในโฟลเดอร์ข้อมูลของเซิร์ฟเวอร์ (`/data/edge-app`) deploy เซิร์ฟเวอร์ใหม่แล้วยังอยู่
   - ถ้าเผยแพร่ผิด กด **ถอนออก** ได้ รีโมตจะไม่เห็นอัปเดตนั้นอีก

### 7.2 คนถือรีโมต อัปเดตในแอป

1. เปิดแอป แอปจะตรวจหาอัปเดตเอง (หรือเลื่อนลงไปที่ **อัปเดตแอป** แล้วกด **ตรวจหาอัปเดต**)
2. ถ้ามีเวอร์ชันใหม่ ด้านบนจะขึ้นแถบ "มีเวอร์ชันใหม่ 0.3.1" กด **อัปเดตเป็น 0.3.1**
3. **ครั้งแรกเท่านั้น** Android จะเปิดหน้า "ติดตั้งแอปที่ไม่รู้จัก" ของ 13STORE Edge:
   เปิดสวิตช์ **อนุญาตจากแหล่งนี้** กด **ย้อนกลับ** แล้วกด **อัปเดตเป็น 0.3.1** อีกครั้ง
4. แอปจะหยุด Gateway เอง (ถ้ากำลังทำงาน) ดาวน์โหลดไฟล์ และตรวจว่าไฟล์ไม่เสียและเซ็นด้วยกุญแจเดียวกัน
5. Android ถามว่า "ต้องการอัปเดตแอปนี้ไหม" กด **อัปเดต**
6. แอปปิดแล้วเปิดใหม่เป็นเวอร์ชันใหม่ **การจับคู่และคีย์ยังอยู่** ถ้า Gateway ทำงานอยู่ก่อนอัปเดต
   จะเริ่มทำงานต่อเอง และมีแจ้งเตือน "อัปเดตเป็น 0.3.1 แล้ว"

| ถ้าแอปขึ้นว่า | ทำอย่างไร |
|---|---|
| เซิร์ฟเวอร์ยังไม่มีไฟล์อัปเดตแอป | ผู้ดูแลยังไม่ได้เผยแพร่ (ข้อ 7.1) |
| เป็นเวอร์ชันล่าสุดแล้ว | ไม่ต้องทำอะไร |
| ไฟล์ที่ดาวน์โหลดมาเสีย | กด **ลองใหม่** (มักเกิดจาก Wi-Fi หลุดระหว่างดาวน์โหลด) |
| ไฟล์อัปเดตนี้ถูกเซ็นด้วยกุญแจคนละชุด | ผู้พัฒนาสร้าง APK ด้วยกุญแจคนละชุดกับที่ติดตั้งอยู่ ให้ผู้พัฒนาสร้างใหม่ด้วยกุญแจเดิมใน `~/.13store/` ถ้าหากุญแจเดิมไม่เจอจริงๆ ต้องถอนแอป ติดตั้ง APK ใหม่ด้วยมือ แล้วจับคู่ใหม่ |
| เซิร์ฟเวอร์ไม่รับคีย์ของรีโมตนี้ | จับคู่ใหม่ (ข้อ 3) แล้วค่อยอัปเดต |
| ยกเลิกการอัปเดตแล้ว | กด **อัปเดต** ใหม่เมื่อพร้อม แอปยังเป็นเวอร์ชันเดิม และ Gateway กลับมาทำงานเหมือนก่อน |

ผู้พัฒนาต้อง **เพิ่ม versionCode ทุกครั้ง** ก่อนสร้าง APK ที่จะให้รีโมต (`apps/edge-android/app/build.gradle.kts`)
และต้องเซ็นด้วยกุญแจเดิมใน `~/.13store/` เสมอ เก็บสำรองโฟลเดอร์นั้นไว้

## 8. เรื่องความปลอดภัย

- คีย์ Gateway ไม่แสดงบนหน้าจอ ไม่อยู่ในบันทึก และเก็บแบบเข้ารหัสด้วยกุญแจของ Android Keystore
  ในพื้นที่ส่วนตัวของแอป ไม่ถูกสำรองออกจากเครื่อง
- รหัสจับคู่ใช้ได้ครั้งเดียว 10 นาที เซิร์ฟเวอร์เก็บรหัสแบบแฮช และหยุดรับชั่วคราวถ้ามีคนเดารหัสผิดหลายครั้ง
- ถ้ารีโมตหาย: ในหน้าเว็บ ผู้ดูแล → การ์ด **API keys** → กด **ยกเลิกคีย์** ของ `... (paired)` ของรีโมตนั้น
- การจับคู่ทุกครั้งถูกบันทึกใน Audit log (`edge.pairing_code`, `edge.paired`)
- การเผยแพร่และดาวน์โหลดอัปเดตแอปก็ถูกบันทึก (`edge.app_publish`, `edge.app_download`)
  ดาวน์โหลดได้เฉพาะรีโมตที่จับคู่แล้ว (ใช้คีย์ Gateway) และแอปติดตั้งเฉพาะไฟล์ที่เซ็นด้วยกุญแจเดียวกับแอปเดิม
