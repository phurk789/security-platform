# คู่มือแอป 13STORE Edge บนรีโมต SIYI UniRC 7 Pro

แอปนี้ทำหน้าที่เดียวกับชุด Termux เดิม (`deploy/remote/`) คือรัน Gateway บนรีโมต
ให้รถส่งข้อมูลและวิดีโอขึ้นแพลตฟอร์ม แต่ **ไม่ต้องพิมพ์คำสั่งและไม่ต้องพิมพ์คีย์**
มีแค่ปุ่ม "จับคู่", "เริ่ม" และ "หยุด"

- จับคู่ครั้งเดียวด้วยรหัส 6 หลักจากหน้าเว็บ แอปจะได้คีย์ Gateway เองโดยไม่มีใครเห็นคีย์
- ปิดจอได้ แอปยังทำงานต่อ และมีแจ้งเตือนค้างไว้ให้รู้ว่ากำลังทำงาน
- หน้าจอแอปบอกสถานะ 3 อย่าง: เชื่อมต่อเซิร์ฟเวอร์ได้ไหม, มีสัญญาณจากรถไหม, ส่งวิดีโออยู่ไหม

> **กฎสำคัญ:** ลิงก์ข้อมูลของรถใช้ได้ **ทีละโปรแกรม** ถ้าจะใช้แอปนี้ต้องปิด UniGCS ก่อน
> และถ้าจะเปิด UniGCS ต้องกด "หยุด" ในแอปก่อน

## 1. สิ่งที่ต้องเตรียม

| อะไร | ใครทำ |
|---|---|
| ไฟล์ `13store-edge-0.1.0.apk` (ได้จากผู้พัฒนา หรือโฟลเดอร์ `apps/edge-android/dist/`) | ผู้พัฒนา |
| รีโมตต่อ Wi-Fi วงเดียวกับเซิร์ฟเวอร์ (192.168.20.x) | หน้างาน |
| บัญชีผู้ดูแล (admin) ของหน้าเว็บ http://192.168.20.13:8090 | ผู้ดูแล |
| ลงทะเบียนรถ UGV-01 ในหน้าเว็บแล้ว (ดูข้อ 3.1) | ผู้ดูแล |

ถ้ารีโมตเคยใช้ชุด Termux ให้ **หยุดชุดเดิมก่อน** (เปิด Termux แล้วพิมพ์ `./stop.sh` หรือกดปุ่ม Stop บนหน้าจอหลัก)
เพราะ Gateway สองตัวใช้ลิงก์ข้อมูลพร้อมกันไม่ได้ ถ้าแอปใช้งานได้ดีแล้วจะลบ Termux ทิ้งก็ได้

## 2. ติดตั้งแอป (ครั้งแรก)

1. คัดลอกไฟล์ APK ลงรีโมต ใช้สาย USB, แฟลชไดรฟ์ หรือดาวน์โหลดผ่านเบราว์เซอร์บนรีโมตก็ได้
2. บนรีโมตเปิดแอป **Files** (ตัวจัดการไฟล์) แล้วแตะไฟล์ `13store-edge-....apk`
3. ถ้าขึ้นว่า "ไม่อนุญาตให้ติดตั้งแอปจากแหล่งนี้" ให้กด **การตั้งค่า** แล้วเปิด **อนุญาตจากแหล่งนี้**
   จากนั้นกดย้อนกลับ
4. กด **ติดตั้ง** แล้วรอจนเสร็จ จากนั้นกด **เปิด**
5. แอปชื่อ **13STORE Edge** (ไอคอนเสาอากาศสีขาวบนพื้นน้ำเงินเข้ม)

> ถ้า Play Protect เตือนว่า "แอปไม่รู้จัก" ให้กด "ติดตั้งต่อ" เพราะแอปนี้ไม่ได้มาจาก Play Store

## 3. จับคู่รีโมตกับแพลตฟอร์ม (ครั้งเดียว)

### 3.1 ผู้ดูแล ทำบนหน้าเว็บ

1. เปิดหน้าเว็บด้วยที่อยู่ในเครือข่าย **http://192.168.20.13:8090** แล้วเข้าสู่ระบบเป็นผู้ดูแล
   (ห้ามใช้ `localhost` เพราะ QR จะพาไปที่อยู่ที่รีโมตเข้าไม่ถึง หน้าเว็บจะเตือนถ้าเปิดแบบนั้น)
2. ไปที่ **ผู้ดูแล**
3. ถ้ายังไม่เคยลงทะเบียนรถ: ในการ์ด **Edge Gateway และอุปกรณ์** พิมพ์ `UGV-01` เลือก `UGV` แล้วกด **ลงทะเบียน**
4. ในการ์ด **จับคู่รีโมต (Edge)** ค่าที่ตั้งไว้ให้ใช้ได้เลย:
   - ชื่อ: `SIYI UniRC 7 Pro`
   - รหัส Gateway: `edge-unirc-01`
   - รหัสรถ: `UGV-01`
   - ที่อยู่กล้อง RTSP: `rtsp://192.168.144.25:8554/main.264` (ถ้าไม่ต้องการวิดีโอให้เว้นว่าง)
5. กด **สร้างรหัสจับคู่** จะได้ตัวเลข 6 หลักกับ QR **ใช้ได้ 10 นาที และใช้ได้ครั้งเดียว**
6. บอกตัวเลข 6 หลักกับคนที่ถือรีโมต (บอกทางโทรศัพท์หรือวิทยุก็ได้) ไม่ต้องส่งคีย์ใดๆ

### 3.2 คนถือรีโมต ทำในแอป

1. เปิดแอป **13STORE Edge** จะเห็นหัวข้อ **จับคู่กับแพลตฟอร์ม**
2. ช่องที่อยู่เซิร์ฟเวอร์มี `http://192.168.20.13:8090` ใส่ไว้ให้แล้ว (แก้ได้ถ้าเซิร์ฟเวอร์ย้าย)
3. พิมพ์ตัวเลข 6 หลัก แล้วกด **จับคู่**
   (ถ้ารีโมตมีกล้อง จะมีปุ่ม **สแกน QR** ให้กดแทนการพิมพ์ก็ได้)
4. ถ้าสำเร็จ หัวหน้าจอจะเปลี่ยนเป็น `edge-unirc-01 · พื้นที่ ... · http://192.168.20.13:8090`
   และในหน้าเว็บรหัสนั้นจะขึ้นป้าย **จับคู่แล้ว** พร้อมชื่อรุ่นรีโมต

ถ้าจับคู่ `edge-unirc-01` ซ้ำ (เช่น ลงแอปใหม่) คีย์ที่ได้จากการจับคู่ครั้งก่อนจะถูกยกเลิกให้เองโดยอัตโนมัติ
ส่วนคีย์ที่เคยสร้างเองสำหรับชุด Termux จะไม่ถูกยกเลิก ถ้าเลิกใช้ Termux แล้ว ผู้ดูแลกด **ยกเลิกคีย์** ของคีย์นั้นในการ์ด **API keys** ได้

## 4. ใช้งานประจำวัน

### เริ่มงาน

1. **ปิด UniGCS ก่อน:** ไปที่ ตั้งค่า → แอป → UniGCS → **บังคับหยุด** (Force stop)
2. เปิดรถ และรอให้ลิงก์ของรีโมตต่อกับรถ
3. เปิดแอป **13STORE Edge** แล้วกดปุ่มสีเขียว **เริ่ม**
   - ครั้งแรกระบบจะถามเรื่องการแจ้งเตือน ให้กด **อนุญาต**
4. รอประมาณ 10 วินาที ดูสถานะ (จุดสีเขียว = ปกติ):

| หัวข้อ | ปกติจะขึ้นว่า |
|---|---|
| เซิร์ฟเวอร์ | ● เชื่อมต่อ ws://192.168.20.13:8090 แล้ว |
| รถ | ● UGV-01: สัญญาณจากรถปกติ (ข้อมูลล่าสุด 0.5 วินาทีที่แล้ว) |
| วิดีโอ | ● UGV-01: กำลังส่งวิดีโอ h264 ขึ้นแพลตฟอร์ม |

5. ในหน้าเว็บ รถ UGV-01 จะขึ้นเป็น **LIVE** และเห็นวิดีโอจากกล้อง
6. **ปิดจอรีโมตได้เลย** แอปยังทำงานต่อ บนแถบแจ้งเตือนจะมี "Gateway edge-unirc-01" ค้างไว้
   พร้อมสรุปสั้นๆ เช่น `เซิร์ฟเวอร์ ✓ · UGV-01 ✓ · วิดีโอ ✓`

### เลิกงาน หรือจะใช้ UniGCS

- กดปุ่มสีแดง **หยุด** ในแอป หรือกด **หยุด** จากแถบแจ้งเตือนก็ได้
- รอจนหัวข้อขึ้นว่า **Gateway หยุดอยู่** แล้วจึงเปิด UniGCS

> รถจะอยู่ในโหมดดูอย่างเดียว (SHADOW) จนกว่าหัวหน้างานจะเลื่อนขั้นในหน้าเว็บหลังทดสอบความปลอดภัย
> แอปไม่ได้เปลี่ยนเรื่องนี้

| ● UGV-01: เซิร์ฟเวอร์ไม่รับ: Device is not registered | ยังไม่ได้ลงทะเบียนรถในหน้าเว็บ | ผู้ดูแลลงทะเบียน UGV-01 (ข้อ 3.1 ขั้น 3) แล้วกด หยุด → เริ่ม ในแอป |
| ● UGV-01: รอที่อยู่ส่งวิดีโอจากเซิร์ฟเวอร์ | เซิร์ฟเวอร์ยังไม่ได้เปิดระบบรับวิดีโอ | แจ้งผู้พัฒนา (ตั้ง MEDIA_INGEST_URL บนเซิร์ฟเวอร์ ดู `deploy/office-13/README.md`) |
| วิดีโอ: ... connection refused / timed out | กล้องยังไม่เปิด หรือที่อยู่กล้องผิด | ตรวจว่ากล้องเปิดอยู่ แอปจะลองใหม่ให้เอง (ทุก 2–30 วินาที) |
| วิดีโอขึ้น "hevc" แต่หน้าเว็บไม่มีภาพ | กล้องส่งภาพแบบ H.265 ซึ่งเบราว์เซอร์เปิดไม่ได้ | ตั้งกล้องให้ส่ง H.264 (main stream) |
| Gateway หยุดเอง (รหัส ...) จะเริ่มใหม่ใน ... วินาที | Gateway ล่ม แอปกำลังเปิดใหม่ให้เอง | ถ้าเป็นซ้ำๆ กด **ดูเพิ่ม** ในหัวข้อบันทึก ถ่ายรูปหน้าจอส่งผู้พัฒนา |

บันทึกไม่มีคีย์ และรหัสผ่านในที่อยู่ส่งวิดีโอถูกปิดเป็น `***`

## 7. อัปเดตแอป

ติดตั้งไฟล์ APK ใหม่ทับได้เลย (ทำแบบข้อ 2) การจับคู่และคีย์ยังอยู่ ไม่ต้องจับคู่ใหม่
ต้องหยุด Gateway ก่อนติดตั้ง แล้วกด **เริ่ม** ใหม่หลังติดตั้ง

ถ้าติดตั้งทับแล้วขึ้นว่า "แอปขัดแย้งกับแพ็กเกจที่มีอยู่" แปลว่า APK ถูกเซ็นด้วยกุญแจคนละชุด
ให้ถอนแอปเดิมก่อน แล้วติดตั้งใหม่และจับคู่ใหม่ (ผู้พัฒนาต้องเก็บสำรองโฟลเดอร์ `~/.13store/` ที่ใช้เซ็นแอปไว้)

## 8. เรื่องความปลอดภัย

- คีย์ Gateway ไม่แสดงบนหน้าจอ ไม่อยู่ในบันทึก และเก็บแบบเข้ารหัสด้วยกุญแจของ Android Keystore
  ในพื้นที่ส่วนตัวของแอป ไม่ถูกสำรองออกจากเครื่อง
- รหัสจับคู่ใช้ได้ครั้งเดียว 10 นาที เซิร์ฟเวอร์เก็บรหัสแบบแฮช และหยุดรับชั่วคราวถ้ามีคนเดารหัสผิดหลายครั้ง
- ถ้ารีโมตหาย: ในหน้าเว็บ ผู้ดูแล → การ์ด **API keys** → กด **ยกเลิกคีย์** ของ `... (paired)` ของรีโมตนั้น
- การจับคู่ทุกครั้งถูกบันทึกใน Audit log (`edge.pairing_code`, `edge.paired`)
