# ชุดเซิร์ฟเวอร์สำหรับออกงาน (Event kit)

ใช้คอม Windows เครื่องเดียว (เช่น OneX) เป็นเซิร์ฟเวอร์ของระบบในงาน **แทนเครื่อง .13** ไม่ต้องลง Docker
ทุกอย่างอยู่ในโฟลเดอร์นี้ (โปรแกรม หน้าเว็บ ตัวส่งวิดีโอ และข้อมูล) แตกไฟล์แล้วดับเบิลคลิกใช้ได้เลย

```
Router (Wi-Fi ของงาน)
 ├─ คอมเครื่องนี้ = เซิร์ฟเวอร์ + วิดีโอ        → START.cmd
 ├─ จอ / โน้ตบุ๊ก / แท็บเล็ต                   → เปิดเว็บ http://<ที่อยู่เครื่องนี้>:8090
 ├─ รีโมต SIYI (แอป Edge) ของ UGV-01, UGV-02  → จับคู่ใหม่กับเครื่องนี้
 └─ Pi บนรถ / กล่อง AI Jetson (ถ้าเอาไป)
```

## ไฟล์ในชุด

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `SETUP.cmd` | ตั้งค่าเครื่องครั้งแรก (ต้องต่อเน็ต): เปิด Firewall ให้เครื่องอื่นเข้าได้, ไม่ให้เครื่องหลับตอนเสียบชาร์จ, ดาวน์โหลดตัวส่งวิดีโอ |
| `START.cmd` | เปิดระบบ แล้วบอกที่อยู่สำหรับเปิดเว็บ |
| `STOP.cmd` | ปิดระบบ |
| `MENU.cmd` | เมนูทั้งหมด: เปิด/ปิด, สลับรถจริง/รถจำลอง, นำเข้าข้อมูล, ให้เปิดเองตอนล็อกอิน |
| `import\*.tgz` | ข้อมูลจากเครื่อง .13 (ถ้ามี) เปิดครั้งแรกระบบนำเข้าให้เอง |
| `data\pilot\`, `data\demo\` | ข้อมูลของโหมดรถจริงและโหมดรถจำลอง (แยกกัน ไม่ปนกัน) |
| `logs\` | บันทึกของระบบ ไว้ดูตอนมีปัญหา |

> **ไฟล์ zip ที่มีโฟลเดอร์ `import\` มีข้อมูลจริงของระบบ** (บัญชีผู้ใช้ กุญแจ Gateway) ส่งต่อด้วยมือเท่านั้น อย่าส่งทางแชทหรืออัปโหลดขึ้นเน็ต

## ขั้นตอน

### 1. ก่อนวันงาน (ที่ออฟฟิศ มีเน็ต)

1. แตกไฟล์ `13store-event.zip` ไว้ที่ไดรฟ์ C เช่น `C:\13store-event\` (ไม่ควรวางในโฟลเดอร์ที่ sync ขึ้น OneDrive)
2. ดับเบิลคลิก **`SETUP.cmd`** → กด **Yes** ตอนเครื่องขอสิทธิ์ → รอจนขึ้น "ตั้งค่าเครื่องเสร็จแล้ว"
3. ดับเบิลคลิก **`START.cmd`** → เบราว์เซอร์เปิดหน้าเว็บให้เอง และหน้าต่างบอกที่อยู่ เช่น `http://192.168.1.10:8090`
4. เข้าสู่ระบบด้วยบัญชีเดิมของเครื่อง .13 (ถ้าชุดนี้มีข้อมูลจาก .13) แล้วเช็คว่าเห็นรถและผู้ใช้ครบ

### 2. ตั้ง Router

- ตั้งให้คอมเครื่องนี้ได้ **ที่อยู่เดิมทุกครั้ง** (เมนูของ router ชื่อประมาณ *DHCP Reservation* / *Static lease* / *Address reservation*) เพราะรีโมตและ Pi จำที่อยู่เซิร์ฟเวอร์ไว้ ถ้าที่อยู่เปลี่ยน ต้องจับคู่ใหม่
- ถ้าที่งานไม่มีเน็ต: **แผนที่ดาวเทียมและแผนที่ถนนจะว่าง** (โหลดจากอินเทอร์เน็ต) ต่อ router กับซิม 4G หรือฮอตสปอตมือถือ ส่วนอย่างอื่น (ขับรถ ภาพกล้อง สั่งงาน) ทำงานได้โดยไม่ต้องมีเน็ต

### 3. ต่อรถเข้ากับเครื่องนี้

1. รีโมต SIYI: ต่อ Wi-Fi ของ router ตัวนี้
2. หน้าเว็บ (เปิดจากที่อยู่ของเครื่องนี้ ไม่ใช่ localhost) › แอดมิน › อุปกรณ์และการเชื่อมต่อ › การ์ดจับคู่ › สร้างรหัสจับคู่
   - UGV-01: รหัส Gateway `edge-unirc-01`, บอร์ดมอเตอร์ RCU-ND, ติ๊กกล้อง
   - UGV-02: รหัส Gateway `edge-unirc-02`, ไม่มีปุ่มเกียร์ และแก้ JSON ตาม `deploy/remote/README_TH.md` (reverseSteer)
3. บนรีโมต: แอป Edge › จับคู่ › สแกน QR ที่หน้าเว็บ
4. Pi บนรถ (ถ้าใช้): จับคู่ใหม่ด้วยคำสั่งที่การ์ดให้ (`sudo 13store-edge pair …`)
5. หัวหน้าเวรเลื่อนรถเป็น LIVE_MANUAL ก่อนขับจากเว็บ (เหมือนที่ออฟฟิศ)

> จับคู่กับเครื่องนี้แล้ว รีโมตจะไม่ต่อกับเครื่อง .13 จนกว่าจะจับคู่กลับ ตอนกลับมาออฟฟิศให้จับคู่กับ .13 ใหม่

### 4. ตำแหน่งพื้นที่งานบนแผนที่

ไซต์ในระบบผูกกับพื้นที่ออฟฟิศ ถ้ารถจริงมี GPS ที่งาน ให้ไป แอดมิน › **ไซต์และแผนที่** ย้ายตำแหน่งไซต์มาที่พื้นที่งาน และวาด **พื้นที่ปฏิบัติการ** ก่อนสั่งรถวิ่งเอง
(ใบอนุญาตทดลองใช้ได้ 1 ไซต์ จึงใช้วิธีย้ายไซต์เดิม)

### 5. วันงาน

- เสียบสายชาร์จคอมไว้ตลอด
- กด **`START.cmd`** แล้วเปิดเว็บจากจอ/แท็บเล็ตตามที่อยู่ที่ขึ้น
- อยากให้ระบบเปิดเองทุกครั้งที่เปิดเครื่องและล็อกอิน: `MENU.cmd` › 7 › `on`
- สำรองไว้: `MENU.cmd` › 4 สลับเป็น **รถจำลอง** ได้ทันทีถ้ารถจริงมีปัญหา (ข้อมูลแยกกัน สลับกลับได้)

## มีปัญหา

| อาการ | ทำอะไร |
| --- | --- |
| เครื่องอื่นเปิดเว็บไม่ได้ แต่บนเครื่องนี้เปิดได้ | รัน `SETUP.cmd` อีกครั้ง (Firewall) และเช็คว่าเครื่องอื่นอยู่ Wi-Fi เดียวกัน |
| หน้าเว็บขึ้น แต่ไม่มีภาพกล้อง | `MENU.cmd` ดูบรรทัด "วิดีโอ" ถ้าขึ้น "ไม่มีตัวส่งวิดีโอ" ให้ต่อเน็ตแล้วรัน `SETUP.cmd` |
| ที่อยู่เครื่องเปลี่ยน | ตั้งจองที่อยู่ใน router (ข้อ 2) แล้ว `MENU.cmd` › 3 เปิดใหม่ หรือกำหนดเองด้วย `powershell -File event.ps1 ip 192.168.1.10` |
| เปิดระบบไม่สำเร็จ | ดูข้อความที่ขึ้น และไฟล์ `logs\server.err.log` ส่งให้ทีมดู |
| อยากเริ่มข้อมูลใหม่ทั้งหมด | ปิดระบบ แล้วย้ายโฟลเดอร์ `data\pilot` ออกไปที่อื่น (ระบบสร้างใหม่ และแสดงรหัสผู้ดูแลครั้งเดียวตอนเปิด) |

## สำหรับทีม (สร้างชุดนี้)

```bash
npm run kit:event                      # deploy/event/dist/13store-event.zip
npm run kit:event -- --with-13-data    # รวมข้อมูลล่าสุดจากเครื่อง .13 (สำรองตอน deploy ครั้งล่าสุด) ไว้ใน import\
```

- ใช้ Node ของเครื่องที่สร้าง (ต้อง 22.5 ขึ้นไป) เป็น `node\node.exe` ในชุด
- ใส่ `mediamtx.exe` (MediaMTX 1.9.3 Windows amd64) ไว้ที่ `deploy/event/cache/` ถ้าอยากให้ชุดมีตัวส่งวิดีโอในตัว (ไม่ต้องใช้เน็ตตอน SETUP)
- ข้อมูลจาก .13 ที่รวมมาคือไฟล์สำรองล่าสุดตอน deploy (`C:\Server\thermal\backups`) ของที่เปลี่ยนหลังจากนั้นจะไม่มา
