# UGV-01: ผังสายและค่าที่ตั้ง (บอร์ด UniFC 6 Pico + บอร์ดมอเตอร์ CODBOT RCU-ND)

อัปเดต 28 ต.ค. 2026 ตอนเปลี่ยนจาก Matek H743-WING มาเป็น UniFC 6 Pico

## อุปกรณ์

| ส่วน | รุ่น |
|---|---|
| บอร์ดสั่งงาน | SIYI UniFC 6 Pico, ArduRover V4.7.0 (1511f271) |
| บอร์ดขับมอเตอร์ | CODBOT RCU-ND (มี MCU ของตัวเอง ไม่มีคู่มือ ผังขาด้านล่างได้จากการทดลอง) |
| ลิงก์ | กล่อง SIYI บนรถ + รีโมต UniRC 7 Pro |
| ค่าที่ตั้ง | [`ugv-01-unifc6pico.param`](ugv-01-unifc6pico.param) โหลดใน Mission Planner ได้ |

## ผังสาย

**บนบอร์ด Pico**

| ช่องบน Pico | ต่อกับ |
|---|---|
| RC_IN | S.Bus จากกล่อง SIYI |
| TELEM2 | สาย UART (Datalink) จากกล่อง SIYI ที่ 57600 |
| GPS1 | GPS |
| **ช่อง 1** | RCU-ND **C7** (เลี้ยว) |
| **ช่อง 3** | RCU-ND **C9** (เดินหน้า/ถอยหลัง) |
| **ช่อง 4** | RCU-ND **C6** (เกียร์ความเร็ว มาจากสวิตช์ ch11) ใช้สายจัมเปอร์เส้นเดียว ขาสัญญาณอย่างเดียว |
| ช่องอื่น | ว่าง |

ปลั๊กเซอร์โวทุกตัวต้อง**เสียบตั้งลงช่องเดียว** หันสายดำไปฝั่งเดียวกับสายดำของปลั๊ก RC_IN ห้ามเสียบนอนพาดหลายช่อง

**บนบอร์ด RCU-ND** หัวต่อรับสัญญาณรีโมตเป็นตาราง 5 คอลัมน์ ชื่อ **C6 C7 C8 C9 A8** (เป็นชื่อขาของชิป) × 3 แถว: แถวบน = สัญญาณ (สายขาว), แถวกลาง = ไฟ +, แถวล่าง = กราวด์

| ขา RCU-ND | หน้าที่ (จากการทดลอง) |
|---|---|
| C6 | **เกียร์**: ไม่มีสัญญาณหรือต่ำกว่าประมาณ 1300 = ปิด (รถไม่วิ่ง), 1350–1500 = ช้า, สูงกว่า 1500 ยิ่งสูงยิ่งเร็ว (1725 กลาง, 2100 เร็วกว่า 1950) |
| C7 | เลี้ยว |
| C8 | ไม่พบว่ามีผล ปล่อยว่าง |
| C9 | เดินหน้า/ถอยหลัง (บอร์ด Pico ส่ง 1000–2000) |
| A8 | ยังไม่ได้ทดสอบ ปล่อยว่าง |

## รีโมต UniRC 7 Pro

| สวิตช์/สติ๊ก | หน้าที่ |
|---|---|
| สติ๊กขวา ซ้าย/ขวา (ch1) | เลี้ยว |
| สติ๊กซ้าย ขึ้น/ลง (ch3) | เดินหน้า/ถอยหลัง |
| ch10 | โหมด: ล่าง = HOLD (หยุดรอ), กลาง/บน = MANUAL |
| ch11 | ความเร็ว 3 ระดับ: รีโมตส่ง 1050 / 1500 / 1950 → Pico แปลงเป็น 1500 / 1725 / 2100 ไปที่ C6 = **ช้า / กลาง / เร็ว** |
| ch12 | arm / disarm |

## ความปลอดภัย

- **ตัวหยุดที่แน่นอนที่สุดคือสวิตช์ ON/OFF ของ RCU-ND** ก่อนขับบนพื้นทุกครั้ง ต้องมีคนอยู่ใกล้สวิตช์นี้
- รีโมตหลุด: Pico เข้า HOLD ภายใน 1.5 วินาที และช่อง 4 หยุดส่งสัญญาณไป C6 RCU-ND จึงหยุดด้วยอีกชั้น
- gateway หลุด (ปิด Edge ระหว่างที่รถเปิดอยู่): Pico เข้า HOLD ให้โยก ch10 ลงแล้วขึ้นเพื่อขับต่อ
- ขับจากเว็บ: gateway สั่งเฉพาะ ch1/ch3 ส่วน ch10, ch11 และ ch12 ยังอยู่ที่รีโมตเสมอ

## ทำไมรถถึงเดินหน้าเองไม่ยอมหยุด (27–28 ต.ค.)

ตั้งแต่ผังเดิมของคนก่อนหน้า ขาเดินหน้า/ถอยหลังจริงของ RCU-ND (**C9**) **ไม่เคยมีสายต่อ** ขาจึงลอยและรับสัญญาณรบกวนจากสายเลี้ยวที่อยู่ข้าง ๆ รถเลยเดินหน้าเองหลังเลี้ยว แล้วค้างไว้ อาการนี้การ disarm หรือสวิตช์ HOLD แก้ไม่ได้ เพราะบอร์ดสั่งงานส่งค่ากลางอยู่แล้ว พอต่อ C9 แล้วอาการหายไป

## ประวัติการหาผังขา C6 (28 ต.ค.)

- C6 ส่ง 1050 / 1500 / 1950 ตรง ๆ: 1050 ไม่วิ่ง, 1500 ช้า, 1950 เร็ว
- ลองบีบเป็น 1050 / 1275 / 1500: วิ่งได้แค่ 1500 → จุดตัดเปิด/ปิดอยู่ระหว่าง 1275 กับ 1350
- 1350 / 1425 / 1500: วิ่งทุกตำแหน่ง แต่เร็วเท่ากัน → ช่วงต่ำกว่า 1500 คือเกียร์ช้า
- 1500 / 1725 / 1950: ได้ 3 ระดับ ช้า / กลาง / เร็ว
- เกียร์เร็ว 1950 → 2100: เร็วขึ้นอีก (ค่าที่ใช้ตอนนี้; บอร์ด Pico ส่งได้สูงสุด 2200)
