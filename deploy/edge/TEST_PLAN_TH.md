# แผนทดสอบรถจริงครั้งแรก (27 ต.ค. 2026)

**รถ:** UGV-01 (ตีนตะขาบ, SIYI UniFC 6 Pico + UniRC 7 Pro + กล้อง A8 mini)
**Server:** `http://192.168.20.13:8090` (โหมด pilot) · **Edge:** โน้ตบุ๊ก (`deploy/edge`)
**ขั้นตอนตั้งค่าละเอียด:** [`FIRST_CONNECTION_TH.md`](FIRST_CONNECTION_TH.md) (แผนนี้อ้างถึงเป็น "คู่มือ ขั้น N")

## เป้าหมายของวันนี้

1. รถขึ้นบนแพลตฟอร์ม: ตำแหน่ง, ทิศ, แบตเตอรี่, สถานะ และภาพจากกล้องบนรถ
2. พิสูจน์ว่าระบบปลอดภัยเมื่อสัญญาณหลุด และ**ไม่มีคำสั่งจากแพลตฟอร์มไปถึงรถ** (โหมด `SHADOW`)
3. เก็บค่าที่วัดได้จริง (ความหน่วงภาพ, ความแม่นยำ GPS) ไว้ใช้ออกแบบงานถัดไป

**ไม่ทำวันนี้:** สั่งรถวิ่งจากแพลตฟอร์ม, เลื่อนโหมดเป็น `LIVE_MANUAL`, arm จากระยะไกล, ต่อสาย S.Bus เข้ากล้อง

## หน้าที่

| หน้าที่ | ทำอะไร | หมายเหตุ |
|---|---|---|
| **ผู้คุมการทดสอบ** | อ่านขั้นตอน สั่งเริ่มหรือหยุดแต่ละข้อ จดผล | |
| **คนขับ (pilot)** | ถือ UniRC 7 Pro ตลอดเวลา arm/disarm และขับด้วยมือเท่านั้น | **ห้ามเป็นคนเดียวกับคนดูหน้าจอ** |
| **ผู้ดูแลความปลอดภัย** | ยืนใกล้ปุ่ม E-stop ดูพื้นที่ สั่งหยุดได้ทุกเมื่อ | ทุกคนต้องหยุดทันทีเมื่อคนนี้สั่ง |
| **คนดูหน้าจอ** | ดูหน้าเว็บด้วยบัญชี supervisor/operator และอ่านค่าบนจอให้คนจด | admin ดูวิดีโอไม่ได้ |

ถ้ามีคนไม่พอ ผู้คุมการทดสอบกับคนดูหน้าจอเป็นคนเดียวกันได้ แต่คนขับต้องแยก

## กฎความปลอดภัย (อ่านให้ทุกคนฟังก่อนเริ่ม)

- ช่วงที่ 1–3: **ยกตีนตะขาบพ้นพื้น** (วางบนขาตั้ง) และรถ **disarm**
- ช่วงที่ 4: รถลงพื้นได้เฉพาะในพื้นที่ปิดที่กั้นไว้ และไม่มีคนอยู่ในรัศมีที่รถวิ่งถึง
- ปุ่ม E-stop จริงต้องอยู่ในระยะเอื้อมของผู้ดูแลความปลอดภัยตลอดเวลา
- ระบบไม่ arm ให้ (`allowRemoteArm: false`) คนขับเป็นคน arm บนรีโมตเองเท่านั้น

**หยุดทันที (E-stop, disarm, ตัดไฟ) ถ้า:**
- รถขยับโดยที่คนขับไม่ได้สั่ง
- รถ arm เองหรือเปลี่ยนโหมดเอง
- **มีคำสั่งใดจากแพลตฟอร์มทำงานบนรถ** ทั้งที่ยังเป็น `SHADOW`
- คนขับคุมรถด้วยรีโมตไม่ได้ หรือมีกลิ่นไหม้ ควัน หรือความร้อนผิดปกติ

หยุดแล้วให้จดเวลาและสิ่งที่เห็น ถ่ายรูปหน้าจอ และเก็บ log (ช่วงที่ 6) ก่อนแก้อะไร

## ช่วงที่ 6 — ปิดงานและเก็บหลักฐาน (~15 นาที)

1. Ctrl+C หยุด gateway และปิดหน้าต่าง MediaMTX (หรือ `~/edge/stop.sh` บนรีโมต)
2. ลำดับปิดไฟ: รถ disarm → ปิดกล้องและรถ → ปิดรีโมต
3. เก็บไฟล์เหล่านี้ไว้ในโฟลเดอร์เดียว:
   - รายงาน probe (`siyi-bench-*.json`)
   - หน้าจอที่ copy มาจากหน้าต่าง gateway และ MediaMTX
   - รูปวัดความหน่วง (ข้อ 2.9) และรูปหน้าจอของแต่ละช่วง
   - ตารางจดผลด้านล่าง
4. ส่งสรุปให้ทีมหรือให้ Claude: ข้อไหนผ่าน/ไม่ผ่าน, ภาพขึ้นไหม, codec, ความหน่วง, ความแม่นยำ GPS — ใช้ต่อในงาน "edge push ภาพเข้า .13"
